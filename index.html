Plant Data Visualization

By Jamie Zheng

The Charts

This project is a data visualization of the various plants based on a Kraggle Dataset by Ariba Shafaqat. The data details plant growth and care recommendations. The data was then visualized using bar charts and chart.js to show the distribution of plants in each category of plant care, with categories like water, soil, growth, and sunlight. Using this data, readers are able to see the different types of plants and each of the needs they require. To make this a bit more relevant, using this visualization, we can learn based on the criteria of New York City's climate and environment, which plant would be best suited to grow in the city.
